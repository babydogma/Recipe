# Правила работы с проектом Portionly

- Не переписывать проект целиком без прямой команды.
- Перед изменениями изучать реальные файлы проекта и текущую реализацию.
- Не удалять существующую рабочую логику без прямой команды или понятного обоснования.
- Не менять структуру данных без объяснения причины и последствий.
- Не переименовывать файлы без прямой команды.
- Не добавлять CSS-хаки в конец файла.
- Не делать дублирующие override-блоки.
- Менять только нужные участки кода.
- После задачи показывать список изменённых файлов.
- После задачи объяснять, что проверено и какие риски остались.
